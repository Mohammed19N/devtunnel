Quickstart

1. Install the CLI

On Linux and macOS:

{{.InstallCmd}}

Or with Homebrew:

brew install mohammed19n/tap/passway

Windows builds and checksums are on the releases page.

2. Sign in and create a token

Sign in with your GitHub account, open CLI tokens in the dashboard and create a token. It is shown only once. Save it on your machine:

passway login <token>

3. Open a tunnel

Start your app, then point Passway at its port:

passway http 3000

The CLI prints your public HTTPS URL and the inspector address. Requests to the URL reach localhost:3000 until you stop the CLI with Ctrl+C. If the connection drops, the CLI reconnects and keeps the same URL.

Inspector

While a tunnel is open, the inspector runs at http://localhost:4040. If that port is taken, the CLI tries 4041 to 4049 and prints the address it chose. It listens on loopback only, and the captured data never leaves your machine.

  • Live list: every request with its method, path, status and timing, and the full headers and body of the request and the response.
  • Replay sends a captured request to your local app again, byte for byte, including signature headers such as Stripe-Signature.
  • Edit & Replay lets you change the method, path, headers or body first.
  • Copy as cURL builds a curl command for the request against your public URL.

The inspector keeps the last 500 requests in memory and stores at most 1 MB of each body. Larger bodies are still forwarded in full; only the stored copy is truncated.

Browser warning page

On the Free plan, someone who opens your tunnel in a browser first sees a page that names the tunnel's owner. After they continue, the browser is not asked again for that tunnel. Requests that are not browser page loads, such as webhooks, API calls and curl, are not affected. To skip the page in your own browser testing, send the Passway-Skip-Warning header. Pro tunnels have no warning page.

Custom domains

On Pro, add a domain under Custom domains in the dashboard, create the DNS records it shows (a CNAME to {{.EdgeHost}} and a TXT record for verification), then verify it. Once verified:

passway http 3000 --domain app.example.com

The certificate for the domain is issued automatically on the first request.

Self-hosting

The server is a single binary, also published as the Docker image ghcr.io/mohammed19n/passway-server. It needs a domain with wildcard DNS and a wildcard TLS certificate. The self-hosting guide covers DNS, TLS, flags and admin commands. Point the CLI at your server with --server https://your-domain.
