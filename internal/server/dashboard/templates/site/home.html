Public URLs for localhost, with a webhook inspector built in

One command gives your local app a public HTTPS URL. Every request that comes through shows up in an inspector on your machine, where you can replay it, edit and replay it, or copy it as cURL.

{{.InstallCmd}}

# or with Homebrew

brew install mohammed19n/tap/passway

# Expose port 3000

passway http 3000

What you get

A public HTTPS URL in one command

passway http 3000 connects your local port to a public URL. Your account's subdomain stays the same between sessions, so you set up a webhook endpoint once.

Every request, inspected

The inspector at localhost:4040 shows the method, path, headers and body of each request and the response your app sent, live as they arrive.

Replay instead of re-triggering

Send a captured webhook to your app again with one click, change it first with Edit & Replay, or copy it as a curl command.

Open source, and you can run it yourself

The CLI is MIT licensed and the server is AGPL-3.0. Run your own server on your own domain as a single binary or a Docker image, with no account needed.
